Что умеет TextTools

Инструмент остаётся локальным скриптом AutoHotkey: состояние и ключ на вашей машине, а к модели уходит только текст выбранного действия.

01

Сетка действий и акселераторы

Вычитка, переписывание, деловой тон, суммаризация, тезисы, таблица, спецификация, разбор кода, вопросы и черновик ответа — с клавишами 1–0 и Q–Y.

02

Любой совместимый API

OpenRouter, OpenAI, прокси Anthropic, локальный Ollama и другие endpoints с `/v1/chat/completions`. Модель по умолчанию и отдельно на действие.

03

Редактор и профили приложений

Кнопки и промпты правятся из трея. Профили подсказывают модели, что текст из IDE, почты, таблицы или трекера задач.

Интерфейс

Сетка действий по хоткею, настройки API, редактор промптов и окно результата — всё из трея на Windows.

Типовые сценарии

Один хоткей покрывает правку формы, переписывание смысла и структурный разбор требований.

Быстрый старт

Установка за пару минут

Нужны AutoHotkey v2 и системный curl.exe. Скрипт install.ps1 копирует файлы в %LOCALAPPDATA% и регистрирует автозапуск.

Открыть инструкцию
powershell 
winget install -e --id AutoHotkey.AutoHotkey
git clone https://github.com/BelyaevAD/TextTools.git
cd TextTools
powershell -ExecutionPolicy Bypass -File .\install.ps1

# Затем: трей → Настройки → API key

Конфиденциальность и стабильность

Ключ лежит только в локальном TextTools.ini. История результатов на диске содержит ваши тексты — не коммитьте её.

  • HTTP к модели идёт через отдельный процесс curl.exe — без WinHTTP внутри AHK.
  • Factory-хоткей Ctrl+Alt+Space: Ctrl+Space часто занят IME и другими хуками.
  • Поддерживается локальный Ollama (http://127.0.0.1:11434/v1).
  • Интерфейс локализуется пакетами lang/*.ini; factory UI — английский.
