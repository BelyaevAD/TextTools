# Platform

Linked from docs/README.md. Supersedes Lib/clipboard.ahk.

`ClipboardProtocol.capture` remembers, clears, copies, waits and restores. `paste` returns `Sent` and leaves the pasted text on the clipboard. `WinHotkeys.start` registers the saved menu and repeat chords. Ctrl+Alt+Space and Ctrl+Shift+Space are used only when the saved menu chord is missing or Windows refuses the saved pair. `ForegroundWatch` skips the shell and this process.

`captureSeconds` sleeps for the caller's `clipWaitSeconds` (0.2–5) instead of spinning. When the clipboard has no text but holds an image or files, capture warns once per session, returns an empty string and leaves that clipboard in place. The API key and the proxy URL are DPAPI blobs for the current user. Their file names are on the schema page. A missing store is an error, the value is not logged, and no password file is written. A second process exits. `popupBeside` opens the action menu and the result window on the cursor's screen, on the side of the anchor that stays nearest the cursor without covering it. The anchor is the input field when the selection is in one, and the cursor when the selection is on a page. `canAcceptText` is true for a Win32 caret or a focused editable control. When it is false the result window opens instead of a paste. A point outside every work area is moved onto the nearest one. `caretScreenPoint` reads that caret before the clipboard capture. It does not open a window. `decoratedFrameSlack` is the invisible Windows resize border around a shown window, and zero elsewhere. `WinHotkeys.swap` drops the previous pair and registers the new one; when both chords are refused, the previous pair stays if it was registered. `installedAutostart` builds the HKCU Run command for the installed exe and does not write this machine's registry. An elevated window that belongs to another process does not receive a paste.
