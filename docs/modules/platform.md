# Platform

Linked from docs/README.md. Supersedes Lib/clipboard.ahk.

`ClipboardProtocol.capture` remembers, clears, copies, waits and restores. `paste` returns `Sent(saved, pasted)`. `restoreAfterPaste` writes `saved` back only while the clipboard still equals `pasted`. A set WAYLAND_DISPLAY is Wayland even when DISPLAY is set. On Windows, `WinHotkeys` registers Ctrl+Alt+Space and Ctrl+Shift+Space with RegisterHotKey, and `ForegroundWatch` skips the shell and this process.

`captureSeconds` sleeps for the caller's `clipWaitSeconds` (0.2–5) instead of spinning. When the clipboard has no text but holds an image or files, capture warns once per session, returns an empty string and leaves that clipboard in place. The API key and the proxy URL are DPAPI blobs for the current user; a missing store is an error, the value is not logged, and no password file is written. A second process focuses the first and exits. `menuPosition` returns the caret, or the cursor when the caret is missing or both coordinates are at most zero, with the same 24px drop and 6px work-area margins as AHK `PositionAndShow`, and it does not open a window. `WinHotkeys.swap` drops the previous pair and registers the new one; when both chords are refused, the previous pair stays if it was registered. `installedAutostart` builds the HKCU Run command for the installed exe and does not write this machine's registry. An elevated window that belongs to another process does not receive a paste.
